# The 2D collie (`rolldog.js`)

The brown-and-white collie from `example/dog-roll-over` is drawn on a canvas card with a pseudo-3D rig: body roll (`rollF` / `rollR`),
leg-pose weights `{ stand, sit, down, flop }`, and a look-at head. It's concatenated into `web/toon.js` after `toonbase.js`, like the trainer.
See the header of `rolldog.js` for every option.
